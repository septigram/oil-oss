# Contributing

Thank you for your interest in Ops Incident Ledger (oil).

## This repository

`septigram/oil-oss` is a **read-only publication mirror** of the application for evaluation and adoption. Development happens in a private repository; we do not accept pull requests here.

## How to give feedback

- Open an [Issue](https://github.com/septigram/oil-oss/issues) for bugs, questions, or feature requests
- Include reproduction steps, environment (Docker / manual), and oil version or release tag when reporting bugs

## Scope

Issues about UI behaviour, sample data, Docker quick start, and documentation are welcome. Internal design and roadmap decisions are out of scope for this repository.
